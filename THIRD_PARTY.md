# Third-party notes

## Mutable Instruments DSP

Preview voices under `web/dsp/*.wasm` are built from Mutable Instruments’
open-source module firmware (Émilie Gillet), which is released under the
**MIT License**. That license already lets you use, modify, and redistribute
the code — including as WebAssembly — as long as the copyright notice stays
with it.

This project does **not** claim ownership of those modules. The preview rack is
a convenience for editing sequences; it is not a hardware clone and is not
affiliated with Mutable Instruments.

Upstream: https://github.com/pichenettes (Mutable Instruments firmware repos)
