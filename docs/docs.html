Install & open

  1. Download BlackSequencer-macOS.zip from the landing page (or Releases).
  2. Unzip. You’ll get Black Sequencer.app.
  3. First open: right-click the app → Open (it’s unsigned, so Gatekeeper may block a normal double-click once).
  4. On first launch the app seeds DEMO BANK and the factory rack into ~/Library/Application Support/BlackSequencer/.

Studio & demo

The home screen has two columns:

  • Studio — projects on this Mac.
  • Card — a mounted volume that already contains a PROJECTS/ folder (your Black Sequencer SD).

Open DEMO BANK (100 BPM) to poke around. Bank 1 has boom-bap NIGHT RIDE and techno GRIDLOCK; later banks add more techno and ambient starters. Create your own project with the name field + Create.

Patterns

  • Four channels: CH1–CH4. Paint on the lane; expand a channel for the piano roll / note editing.
  • M / S mute and solo per channel.
  • Pick bank, pattern slot, tempo, and block length from the top bar.
  • Play / Stop use the preview rack so you can hear the sequence.
  • Save pattern writes the .SEQ (and related project data) back to disk. Save before you copy to a card.

Songs

The Song tab chains patterns the way the module expects — name the song, set pattern slots and repeats, then save. Song files live next to patterns in the bank folder.

MIDI

  • Import MIDI — load an SMF and map up to four tracks or channels onto CH1–4.
  • MIDI in — choose a controller (goes through the app, not browser WebMIDI).
  • Rec — arm recording; notes land on the selected channel while playing (or step-record when stopped).
  • Learn CC / Alt-click rack knobs — map controller knobs to brush or module params.

Rack preview

The Rack tab is a listen-while-you-edit voice, not a hardware clone. Factory patch: Plaits lead, Rings, Plaits bass, Peaks drums → mixer → output. Save your own presets from the rack toolbar. Mute channels on the mixer if you only want to hear one part.

Copy to card

  1. Mount the SD card so the volume root has PROJECTS/ (same layout the module uses).
  2. On the home screen, choose that drive under Card.
  3. Select a studio project → To card (or work on a project already on the card and save there).
  4. Eject, put the card in the Black Sequencer, load the project on the hardware.

Always save the pattern in the editor before transferring. The module reads the files on the card — what you hear in the preview rack is only a sketch.

Run from source

On Linux/Windows, or if you prefer not to use the app:

python3 -m pip install -r requirements.txt
python3 -m blackseq --desktop

Or python3 -m blackseq and open http://127.0.0.1:8765. Full notes live in the repo README.
